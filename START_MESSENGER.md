## 🚀 КАК ИСПОЛЬЗОВАТЬ:

### 1. Открой в браузере:
```
http://localhost:4000
```

### 2. Зарегистрируйся:
- Нажми "Регистрация"
- Введи данные:
  - **Имя пользователя**: любое (например: john)
  - **Email**: любой (например: john@example.com)
  - **Отображаемое имя**: как тебя будут видеть (например: Джон)
  - **Пароль**: любой (например: password123)
- Нажми "Зарегистрироваться"

### 3. Начни общение:
- Перейди на вкладку **"Пользователи"**
- Выбери пользователя для чата
- Начни писать сообщения!

### 4. Для тестирования с двумя пользователями:
- Открой **второе окно браузера** (или режим инкогнито)
- Открой http://localhost:4000
- Зарегистрируй второго пользователя
- Начните переписку!

## 💡 Советы:

### Для тестирования с двумя пользователями:
1. **Окно 1**: Обычный режим браузера
   - Зарегистрируй пользователя "John"
2. **Окно 2**: Режим инкогнито (Ctrl+Shift+N)
   - Зарегистрируй пользователя "Alice"
3. **John → Alice**: Начни чат
4. **Смотри**: Сообщения приходят мгновенно!
